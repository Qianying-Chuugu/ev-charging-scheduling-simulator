# 构建输出目录

## 目录用途

本目录保存编译生成的可执行文件和测试程序，不包含项目源代码。

## 主要产物

| 文件 | 说明 |
| --- | --- |
| `charging_system_gtk4.exe` | GTK 4 图形界面程序 |
| `backend_demo.exe` | 命令行后端演示程序 |
| `test_*.exe` | 各模块和整体联调测试程序 |

## 注意事项

- 文件由 `Makefile` 或 `构建GTK4.bat` 生成，可随时重新构建。
- GTK 前端运行时需要 GTK 4 动态库；仅复制单个 EXE 到其他电脑通常无法运行。
- 发布便携版时应同时打包 GTK 运行库、`data/input` 和 `assets/icons`。
- 通常不建议把本目录中的本地编译产物提交到 Git 仓库。
