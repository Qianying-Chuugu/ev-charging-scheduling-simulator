# 模块 4：充电桩资源管理

## 模块定位

模块 4 使用单链表管理每个站点的充电桩，负责设备增删、状态和功率修改、请求分配、充电推进以及任务完成后的资源释放。

## 数据组织

```text
Station.chargers
    ↓
Charger → Charger → Charger → NULL
```

每个充电桩同时注册到 `EntityStore.chargers` 哈希表，以便按编号快速查询。

## 公开函数

| 函数 | 作用 |
| --- | --- |
| `charger_add` | 向指定站点添加充电桩并注册全局索引 |
| `charger_remove` | 删除未工作的充电桩并注销索引 |
| `charger_find_free` | 返回站点中第一个空闲充电桩 |
| `charger_set_state` | 修改非工作充电桩的状态和初始状态 |
| `charger_set_power` | 修改非工作充电桩功率 |
| `charger_assign` | 把等待请求分配给空闲充电桩 |
| `charger_update` | 按时间和功率推进充电进度 |
| `charger_finish` | 完成任务、注销请求并释放充电桩 |

## 充电流程

```text
charger_find_free
        ↓
charger_assign
车辆=CHARGING，请求=CHARGING，充电桩=BUSY
        ↓
重复 charger_update
        ↓
达到目标电量
        ↓
charger_finish
车辆=FINISHED，充电桩=FREE，请求被注销并释放
```

`charger_update` 根据 `power_kw × minutes / 60` 计算本时间步充入的电量，同时更新车辆电量、请求剩余需求和充电桩剩余时间。

## 故障状态

本模块提供基础状态修改，运行中故障的业务处理由模块 6 完成：如果正在工作的充电桩故障，原请求会重新进入站点等待队列。

## 约束与注意事项

- 正在工作的充电桩不能直接删除、修改功率或通过基础接口改状态。
- 输入功率必须大于 0，初始状态只能为空闲或故障。
- 分配请求时，车辆、请求和充电桩状态必须一致。
- 完成任务会释放请求对象，调用方不能继续使用原请求指针。

## 复杂度

- 添加：链表头插和哈希注册平均 `O(1)`；
- 查找空闲桩、删除指定桩：`O(c)`，`c` 为站内充电桩数；
- 单桩更新和完成：`O(1)`，不计哈希链冲突。

## 依赖

依赖模块 3 的充电桩和请求索引接口。
