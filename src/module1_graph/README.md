# 模块 1：道路图与最短路径

## 模块定位

模块 1 使用邻接表保存带权有向路网，提供节点和道路管理、单源 Dijkstra、路径恢复以及行驶耗电估算。道路的 `travel_minutes` 是最短路权重，`distance_km` 用于统计路径距离和估算耗电。

## 核心数据结构

| 结构 | 作用 |
| --- | --- |
| `GraphNode` | 节点编号、坐标、类型和邻接边链表 |
| `Edge` | 终点下标、距离、通行时间、道路等级和下一条边 |
| `Graph` | 固定上限节点数组和当前节点数 |
| `DijkstraResult` | 起点、最短时间数组和前驱数组 |
| `PathResult` | 可达性、节点序列、总时间和总距离 |

节点类型包括普通路口、车辆位置和充电站入口；道路等级包括支路、次干路、主干路、快速路和接入道路。

| `graph_free` | 释放全部邻接边并清空图 |
| `graph_find_node` | 按业务编号查找节点数组下标 |

### 节点管理

| 函数 | 作用 |
| --- | --- |
| `graph_add_node` | 添加普通道路节点 |
| `graph_add_typed_node` | 添加指定类型的节点 |
| `graph_update_node` | 修改节点坐标 |
| `graph_remove_node` | 删除节点、相关道路并修正边下标 |

### 道路管理

| 函数 | 作用 |
| --- | --- |
| `graph_add_edge` | 添加普通支路级单向边 |
| `graph_add_typed_edge` | 添加指定道路等级的单向边 |
| `graph_update_edge` | 修改已有边的距离和通行时间 |
| `graph_remove_edge` | 删除指定单向边 |

### 路径与能耗

| 函数 | 作用 |
| --- | --- |
| `graph_dijkstra_all` | 从一个起点计算到全部节点的最短通行时间 |
| `graph_path_from_dijkstra` | 根据前驱数组恢复到指定终点的路径 |
| `graph_shortest_path` | 计算单个起终点的便捷封装 |
| `graph_calc_energy` | 按距离和单位里程能耗计算耗电量 |

## Dijkstra 实现流程

```text
初始化 distances=∞、previous=-1
        ↓
起点距离设为 0 并压入最小堆
        ↓
弹出当前距离最小的节点
        ↓
遍历邻接边并执行松弛
        ↓
更短结果写入 distances/previous 并重新入堆
        ↓
最小堆为空后结束
```

恢复路径时从终点沿 `previous` 反向回溯，再翻转为起点到终点的节点序列。

## 复杂度

- 邻接表空间：`O(V + E)`；
- 二叉堆 Dijkstra：`O((V + E) log V)`；
- 路径恢复：`O(L)`，`L` 为路径节点数；
- 按编号查找节点：当前为 `O(V)`。

## 约束与注意事项

- 节点编号不能重复；边的起终点必须存在。
- 距离和通行时间必须为正数；道路等级必须有效。
- 重复的同向边会被拒绝。
- 删除节点会改变后续节点数组下标，因此必须同步修正所有邻接边。
- 模块只计算路径，不修改车辆业务状态。
