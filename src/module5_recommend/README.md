# 模块 5：充电站综合推荐

## 模块定位

模块 5 为指定车辆计算全部充电站的可达性、行驶时间、预计等待时间、充电时间和低电量风险，并按综合评分输出排序结果。

## 核心数据结构

### `Recommendation`

保存一个站点的编号、有效性、不可用原因、路径、时间分解、行驶耗电、到站电量和综合评分。

### `RecommendationList`

保存最多 `MAX_STATIONS` 个候选结果以及实际数量。有效结果排在无效结果之前。

## 公开函数

| 函数 | 作用 |
| --- | --- |
| `recommend_all` | 计算并排序车辆到全部充电站的推荐结果 |
| `recommend_best` | 返回排序后排名第一的有效结果 |

## 推荐流程

1. 从车辆当前位置执行一次单源 Dijkstra。
2. 遍历全部充电站并恢复对应最短路径。
3. 排除道路不可达、车辆电量不足和没有可用充电桩的站点。
4. 根据路径距离估算行驶耗电和到站剩余电量。
5. 调用调度器估算车辆到站后的排队等待时间。
6. 把已经前往同一站点的车辆需求按可用桩数折算为额外等待。
7. 使用站点可用充电桩平均功率估算充电时间。
8. 计算总时间、低电量风险分和最终评分。
9. 按有效性、评分和站点编号执行稳定的确定性排序。

## 候选过滤

无效结果仍保留在列表中，并通过 `reason` 说明原因：

- `road unreachable`：道路不可达；
- `no working charger`：站内没有正常充电桩；
- `battery not enough`：车辆电量不足以到达；
- `station unavailable`：调度器无法估算该站点。

## 评分规则

```text
总时间 = 行驶时间 + 等待时间 + 充电时间
评分   = 总时间 + 低电量风险分
```

当预计到站电量低于 15% 时，每低 1 个百分点增加 2 分风险。

固定行驶能耗率 `ENERGY_PER_KM` 当前为 `0.18 kWh/km`。

## 复杂度

一次推荐执行一次 Dijkstra，并对每个站点恢复路径和估算队列。总体主要由 `O((V + E) log V)` 的最短路和各站点的队列模拟构成。

## 注意事项

- 推荐只生成结果，不会自动提交请求或修改车辆状态。
- `recommend_best` 依赖 `recommend_all` 已完成排序。
- 充电时间按站点可用桩平均功率估算，属于仿真近似值。

## 依赖

依赖模块 1 的路径算法、模块 2 的等待估算和模块 3 的实体查询。
